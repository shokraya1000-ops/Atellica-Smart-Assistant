# باركودات دليل تدريب Atellica – General Operator

ورقة باركودات تُطبع وتوضع جنب جهاز Atellica. الموظف يصوّر الباركود بكاميرا الجوال، فيفتح له ملف PDF فيه صفحة الدليل الأصلية لنفس العنوان.

## محتويات المجلد
| الملف | الوصف |
|---|---|
| `pdf/` | ‏101 ملف PDF: ‏88 ملفاً لكل عنوان، و13 ملفاً لكل وحدة كاملة. الصفحات منسوخة من الدليل الأصلي **بدون أي تعديل**. |
| `qr.html` | ورقة الباركودات الجاهزة للطباعة (7 صفحات A4). |
| `index.html` | قائمة بكل العناوين مع بحث، مناسبة للجوال. |
| `assets/` | ملفات تشغيل الصفحتين (مكتبة الباركود وقائمة العناوين). |

## ⚠️ قبل الرفع: حقوق النشر
الدليل ملك لشركة Siemens Healthineers، وفي الصفحة 3 تنبيه بأنه لا يجوز نسخ أي جزء منه دون موافقة كتابية منها.
**المستودع العام (Public) على GitHub يجعل الدليل متاحاً لأي شخص في العالم.** لذلك:
- الأفضل رفعه على سيرفر داخلي للمستشفى (اطلب ذلك من قسم تقنية المعلومات)، أو
- استخدام مستودع **خاص (Private)** مع GitHub Pages خاصة، وهذه تحتاج حساب GitHub Enterprise للمؤسسة، أو
- أخذ موافقة مندوب Siemens Healthineers قبل النشر العام.

## خطوات الرفع على GitHub Pages
1. ادخل على github.com، واضغط **New repository**، وسمّه مثلاً `atellica`.
2. داخل المستودع اضغط **Add file → Upload files**، واسحب **محتوى** المجلد كله (`index.html` و`qr.html` و`README.md` ومجلد `pdf` ومجلد `assets`)، ثم اضغط **Commit changes**.
   - إذا رفض المتصفح رفع ملفات كثيرة دفعة واحدة، ارفع مجلد `pdf` على دفعتين.
3. اذهب إلى **Settings → Pages**، واختر في **Source**: ‏`Deploy from a branch` → `main` → `/ (root)` ثم **Save**.
4. انتظر دقيقة أو دقيقتين، وسيظهر الرابط بهذا الشكل:
   `https://اسم-المستخدم.github.io/atellica/`

## طباعة ورقة الباركودات
1. افتح الرابط **من الإنترنت** وأضف في آخره `qr.html`، مثل: `https://اسم-المستخدم.github.io/atellica/qr.html`
   - مهم: لا تطبع الورقة وهي مفتوحة من جهازك مباشرة، لأن الباركودات ستحمل رابط جهازك وليس رابط GitHub. الصفحة تعرض تنبيهاً أصفر إذا حصل ذلك.
2. اضغط زر **🖨 طباعة**، واختر ورق A4، وفعّل **Background graphics** (رسومات الخلفية).
3. جرّب باركوداً أو اثنين بجوالك قبل تعليق الورقة.

## تغيير مكان الملفات لاحقاً
إذا نقلتم الملفات لسيرفر آخر، افتح `qr.html` من المكان الجديد، فتُبنى الباركودات تلقائياً على الرابط الجديد. ويمكن أيضاً كتابة رابط مجلد `pdf` يدوياً في الخانة أعلى الصفحة ثم الضغط على **تحديث**.
